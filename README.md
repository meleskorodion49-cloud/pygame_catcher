Catcher Game (Godot & Pygame)

A 2D arcade game built to practice game development architecture, UI mechanics, and event handling. This project transitions from a lightweight Python logic script into a full-scale component-based application using the Godot Engine.

Project Structure
The repository contains a modular asset and scene architecture layout:
 `/mainMenu` — Contains the Main Menu interface scene and button behaviors.
 `/escMenu` — In-game pause menu (`Escape` key menu handling).
 `/platform` — Player controller platform configuration with collision detection.
 `/coin` — Spawning logic and scene nodes for the falling collectible elements.

Tech Stack & Concepts
**Engines & Libraries:** Godot Engine 4.x, Pygame (Python 3)
**Languages:** GDScript, Python
**Patterns Applied:** Object-Oriented Programming (OOP), Signal-driven UI events, AABB Collision Detection, and State Management (Menus vs. Gameplay loop).
